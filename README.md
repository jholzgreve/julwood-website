# julwood-website

Source of [julwood.com](https://julwood.com), the one-page site of Julwood, the independent practice of Julia K. Holzgreve.

- `index.html` is the home page.
- `imprint/index.html` is the imprint and privacy page, linked from the footer.
- `styles.css` holds the styles for both pages.
- `assets/` holds the portrait.
- `fonts/` holds the two typefaces, Newsreader and Instrument Sans, trimmed to the Latin characters and weights the page uses. Both are under the SIL Open Font License; the licence texts sit next to them. The page loads nothing from other servers.
- `CNAME` tells GitHub Pages to serve the site at julwood.com.

The page is published with GitHub Pages from the `main` branch. Any change pushed to `main` goes live within a minute or two.
