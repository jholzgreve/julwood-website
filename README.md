# julwood-website

Source of [julwood.com](https://julwood.com), the one-page site of Julwood, the independent practice of Julia Holzgreve.

- `index.html` is the whole page, with its styles inline in the file.
- `assets/` holds the portrait.
- `CNAME` tells GitHub Pages to serve the site at julwood.com.

The page is published with GitHub Pages from the `main` branch. Any change pushed to `main` goes live within a minute or two.
